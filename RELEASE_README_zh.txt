EFT Raid Assistant 0.8.0 正式版使用说明
====================================

本版本在 0.7.2 的查价、配方、主题和 Tarkov 1.1 识别修复之上，加入赛季服支持和可回滚的软件自动更新链路。

一、这是什么
------------

EFT Raid Assistant 是一个面向中文玩家的 Escape from Tarkov 局内辅助工具。

它用于：
- 鼠标悬停物品后 OCR 识别名称并查价。
- 先用本地缓存的 API 最近低价立即给出建议挂价和净到手，同时展示 24h 均价与采样时间；再按 1.1 手续费公式比较跳蚤净收益与最佳商人收购价。
- 可在“设置 → 查价 → 价格数据”开启智能挂价建议：快速结果先显示，当前物品的 48h 历史分析完成后原位更新，不批量预取。
- 显示 PvE / PvP / 赛季服本地缓存价格。
- 用颜色提示物品价值区间。
- 在右上角显示最多三条查价浮窗。
- 按 F9 打开右上方暗色半透明局内控制窗，可实时调整价格模式、显示语言、提示时长和透明度；只有启用 Gamma 模块后才显示画面增强区域。
- 按 F10 打开左下角局内日志栏；显示时不主动抢焦点，点击后可滚动日志并拖动标题移动。
- 可选开启“关注制作/兑换配方”：在独立页按产物分类或搜索并勾选配方，可查看英文商人名、制作耗时、兑换限购和任务依赖；之后查到所需材料时会在价格浮窗的独立暖色区域醒目提示局内关注用途。
- Settings 的“界面”页可调整主窗口字体大小，范围为 9–18pt，保存后立即生效；配方列表字体与行距会同步按比例调整。
- 提供商人补货倒计时提醒功能。
- 首次启动默认只启用核心查价，并会询问玩家自己的情报中心等级与藏身处管理技能等级；两项默认都是 0，不预填开发者数据。商人补货、藏身处记录和 Gamma 等 Beta 功能可按需开启，保存后立即生效。禁用模块不会显示面板、注册热键、启动后台刷新或应用显示滤镜。
- 主窗口可选择浅色（默认）、深色、夜蓝、樱粉或高对比度主题，并可调节字体大小；局内悬浮窗始终保持暗色沉浸样式。
- 画面增强可选择具体 Windows 显示输出，显示器列表同时标出显示器编号、物理显示器名称和显卡名称；“检测所选显示器”会用原值回写检测逐屏 Gamma Ramp 支持，不改变画面。驱动拒绝明确选中的显示器时会直接报错，避免误改其他屏幕。
- 每个 Gamma 显示方案都可以单独绑定热键，局内可直接切到指定方案。
- 可开启离开自动恢复；当前台既不是 Tarkov 也不是本助手时关闭画面增强，打开 F9 调节时不会误触发。
- 主界面底部固定显示全局运行日志；可拖动分隔线调整高度或一键收起，并记住状态。
- 数据页显示缓存新鲜度、配方/别名/藏身处状态和最近错误，并可导出诊断包。
- 默认开启性能模式，RapidOCR 使用推荐的 2 线程预算；正常查价不会反复写入截图或重载整份价格缓存，Tooltip 使用批量像素运算定位。启动价格更新先使用低流量 ETag 检查并仅在变化时下载，也可选择仅在缓存过期后再检查。
- 从 0.8.0 起，正式版每次启动会自动检测软件更新；发现新版后先询问，确认后自动下载和校验，并在用户再次确认后重启完成安装。

它不会：
- 点击鼠标或移动鼠标。
- 自动购买、出售或整理物品。
- 读取游戏内存。
- 注入游戏进程。
- 修改游戏文件。


二、安装和启动
--------------

1. 请完整解压整个 zip 压缩包。

   推荐路径示例：
   D:\GamesTools\EFT-Raid-Assistant

2. 解压后双击运行：

   EFT Raid Assistant.exe

3. 不需要安装 Python、Miniconda 或 PySide6。

4. 不要只单独复制或发送 exe。

   程序必须和旁边的 _internal 文件夹放在一起运行。

5. 如果 Windows SmartScreen 提示“未知发布者”，可以点击“更多信息”，然后选择“仍要运行”。


三、默认热键
------------

Q   ：局内物品查价
F6  ：识别藏身处升级材料
F7  ：显示/隐藏补货倒计时悬浮窗
F8  ：识别商人倒计时并设置勾选提醒
F9  ：打开/关闭局内控制窗
F10 ：打开/关闭局内日志窗
Ctrl+F9：关闭画面增强并恢复原始画面
Gamma 预设：在 Gamma 面板为每个方案单独绑定热键

常规热键可以在 Settings 中修改；Gamma 方案热键在 Gamma 面板保存预设时绑定。


四、局内物品查价
----------------

1. 打开 Tarkov 装备、背包或容器界面。
2. 把鼠标悬停到要查询的物品上。
3. 等游戏显示完整物品名称 tooltip。
4. 保持 Tarkov 是前台窗口，按 Q。
5. 程序会截图鼠标附近的小区域，定位 tooltip，OCR 识别物品名，并查询本地价格缓存。
6. 查价结果会显示在主界面和右上角浮窗。

如果识别结果明显不对，可以在主界面手动输入物品名重新查询。


五、PvE / PvP / 赛季服价格模式
-----------------------------

主界面可以手动选择 PvE、PvP 或赛季服。

默认是 PvE。

当前版本不再自动 OCR 判断价格模式，这样可以减少截图和误判。

赛季服使用 tarkov.dev 的 pvp-season JSON 数据；如果 JSON 刷新失败，备用 GraphQL 目前只能刷新 PvP/PvE，程序会保留最后一次有效的赛季服缓存。


六、估价逻辑与价格颜色
----------------------

默认基础挂价不额外联网：智能模式关闭时直接使用 API 最近低价，缺失时才回退 24h 均价；少于 10 个挂单、深度未知或两项参考明显分歧只会产生风险提示，不会暗中改写建议挂价。

程序分别计算最近低价和 24h 均价扣除手续费后的净收益。两者较低值仍比商人价高超过 5% 时显示“跳蚤更优”；商人价比两者较高值高超过 5% 时显示“商人更优”；其余显示“收益接近”。手续费或任一出售渠道资料不足时不强行判断渠道。

可选智能挂价使用当前物品最近 48h 的对数价格、时间和挂单深度加权中位数、MAD 异常检测；连续至少 3 个有足够挂单深度的历史点确认价格区间切换后，才跟随活动或删档需求导致的新行情。任何可用智能结果都会更新建议挂价和净到手，低可信度同时显示风险提示；智能结果不改变出售区域或颜色。

普通物品默认按 `max(商人价, min(最近低价净收益, 24h均价净收益))` 显示颜色；多格物品再按格数折算，单格物品不重复显示每格：

0 - 1 万       白色
1 - 2 万       绿色
2 - 5 万       蓝色
5 - 10 万      紫色
10 - 25 万     金色
25 - 50 万     红色
50 万以上      彩色渐变

枪械会使用迷彩绿色提示。

原因是 Tarkov 中枪械本体通常只按下机匣体积计算，但实际出售价值包含大量配件，单格价值容易误导。


关注制作 / 兑换配方（可选）
---------------------------

1. 在 Settings 的“功能”页勾选“关注制作/兑换配方”，保存后立即生效。
2. 打开“关注配方”页，左侧按游戏手册的产物分类选择，右侧按“产物（配方数）→ 英文商人/设施等级与兑换/制作 → 每种材料一行”展开；“耗时 / 限购”列显示制作时间或兑换限购，“任务依赖”列用“英文商人名 · 本地化任务名”显示解锁任务，工具在独立窄栏内打勾；所有列均可拖动表头分隔线调整宽度，也可搜索产物、来源、任务或材料。
3. 勾选具体配方；“已关注总览”可以集中取消、批量删除或清空，并可设置配方提示区域的独立底色与标题强调色。
4. 之后查价命中该配方的所需物品时，右上价格浮窗会在建议售价之后、API 价格明细之前增加独立暖色区域，显示相关产物、当前材料名称与总需求量以及商人/设施等级。最多直接显示三个用途，其余合并为数量提示。

配方数据和游戏手册分类层级随软件版本打包，不会在局内实时联网下载；PvE、PvP 与赛季服分开显示。商人兑换需要在对应模式下分别勾选；相同制作配方会共用关注状态。


七、OCR 引擎
------------

当前统一使用 RapidOCR v5，并优化了物品查价、藏身处识别、完整物品名匹配和简繁字符归一化。


八、右上角浮窗
--------------

查价后会在右上角显示半透明价格卡片。

默认最多保留三条记录。

到时间后自动淡出。

显示时间可以在 Settings 中调整。


九、商人补货提醒
----------------

商人补货提醒仍属于实验功能。

默认热键：
- F8：识别商人倒计时并设置勾选提醒
- F7：显示/隐藏左侧补货倒计时悬浮窗

先勾选要关注的商人，再按 F8 识别倒计时。程序会直接为倒计时有效的商人设置提醒，不再提供手动时间输入或二次“设置提醒”按钮。主界面与左侧半透明、鼠标穿透的汇总悬浮窗会每秒更新所有活动商人的剩余时间；提醒触发时在同一窗口高亮对应商人并按设置播放声音。按 F7 可以随时显示或隐藏汇总窗；用户主动隐藏后，新提醒只更新状态，不会强行重新打开，再按 F7 即可恢复。

主流程建议优先使用局内查价功能。


十、日志和调试文件
------------------

主界面只显示关键结果：
- 查价成功
- 没有匹配物品
- 非 Tarkov 前台窗口
- 当前界面不适合查价

完整运行日志：
debug\latest_run.log

最近一次截图和 OCR 调试图也保存在 debug 文件夹。

如果要反馈问题，可在“文件 → 导出诊断包”或数据页生成 zip 后发给开发者。


十一、常见问题
--------------

1. 按 Q 没反应

   确认程序正在运行，且 Q 没有被其他软件或游戏设置冲突占用。
   也可以在 Settings 中改成其他热键。

2. 提示 Tarkov 不是前台窗口

   重新点击 Tarkov，让游戏成为前台窗口后再按 Q。

3. 识别错物品

   等 tooltip 完整显示后再按热键。
   如果仍然错误，可以手动输入物品名查价，并保留 debug 文件用于排查。

4. 价格模式不对

   在主界面手动选择 PvE、PvP 或赛季服。

5. exe 单独复制后无法运行

   这是正常的。请完整解压并保留 _internal 等目录。

十三、0.7.0 正式版主要更新
--------------------

- 大幅降低局内查价的瞬时 CPU 占用和响应时间；热查询在验证设备上通常约 60–100 毫秒。
- 新增 OCR CPU 占用档位和查价分阶段耗时日志，便于在不同硬件上诊断性能。
- 正常查价改为内存内传递截图、复用已加载价格数据，并向量化 Tooltip 边框定位。
- 修复配方表头右侧空白区域显示成白块的问题。
- 打包资源与用户可写数据彻底分离，首次启动可使用内置价格/配方快照。
- 功能开关保存后立即生效，核心查价以外的实验模块标注 Beta。
- 新增数据状态页、最近错误显示和诊断包导出。
- 新增主窗口、日志高度、配方列宽/展开状态和局内浮窗位置记忆。
- 修复性能模式可能长期跳过价格更新的问题，改为缓存过期后低流量检查。
- 配置、藏身处需求与进度使用原子写入，降低异常退出造成文件损坏的风险。


十四、0.7.2 正式版主要更新
------------------------

- 仓库界面检测会优先选择前台的 EscapeFromTarkov 游戏进程，并排除启动器窗口。
- 找不到前台游戏窗口时，会从有效游戏窗口中选择客户端区域最大的一个。
- 诊断日志会记录选中的窗口标题、进程名和屏幕原点，便于定位多显示器问题。
- 已加入 2560×1600（16:10）截图坐标回归测试；不假定游戏画面存在上下黑边。
- 基础建议挂价直接使用 API 最近低价；挂单稀少或最近低价与 24h 均价严重分歧时明确提示风险。
- 智能挂价建议按需异步运行，可识别持续且有挂单深度支持的新价格区间；任何可用结果都会更新建议挂价并显示可信度。
- 查价卡片优先显示三档出售判断、净到手、建议挂价、两项 API 参考、采样时间和必要风险；价值颜色继续使用保守净收益。


十五、0.8.0 自动更新
-------------------

- 正式打包版本每次启动后自动检查更新，也可从“帮助 → 检查软件更新”手动检查。
- 发现新版本后先询问是否下载；下载过程显示进度，支持取消和断点续传，不影响当前版本继续运行。
- 下载后同时校验文件大小、SHA-256、版本号和 ZIP 必需结构，再询问是否立即重启安装。
- 独立更新助手会在主程序退出后替换 exe 和 `_internal`，保留 `config.json`、`cache`、`data`、`debug` 等用户数据。
- 更新失败时尽力恢复旧运行目录并重新启动；成功或失败结果会在重启后显示。
- 0.8.0 是首个带更新助手的版本，因此从 0.7.2 安装 0.8.0 仍需手动下载完整 ZIP；安装 0.8.0 后，后续正式版即可自动更新。
- 当前默认下载源为 GitHub Release；更新清单已支持多个 HTTPS 镜像地址，后续可按国内实测情况加入对象存储镜像。
- 当 GitHub 最新正式版仍早于自动更新功能、尚未附带更新清单时，手动检查会显示清晰状态，不再暴露 HTTP 404 长错误。
