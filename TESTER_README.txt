EFT Raid Assistant 0.8.0 发布验收清单
===================================

启动
----
1. 完整解压 ZIP，保留 EFT Raid Assistant.exe、EFT Raid Assistant Updater.exe 与 _internal 文件夹。
2. 双击主程序；无需安装 Python、Conda 或 OCR 环境。
3. 0.7.2 不含更新助手，因此首次安装 0.8.0 仍需手动下载完整 ZIP。

自动更新
--------
1. 正式打包版本启动约两秒后应在后台检查更新；无新版或网络失败时不打扰玩家。
2. “帮助 → 检查软件更新”可手动检查，并明确显示最新、发现新版、清单尚未发布或连接失败；旧 Release 缺少清单时不应显示 HTTP 404 长错误。
3. 发现新版后应先询问；确认后显示下载进度，取消后保留 .part 文件用于下次续传。
4. 下载完成后应再次询问重启；未确认时继续运行当前版本。
5. 确认后主程序退出，独立更新助手完成替换并重新启动；重启后显示更新结果。
6. 更新前后的 config.json、cache、data 和 debug 内容必须保留，exe、VERSION 与 _internal 必须来自新包。
7. 下载、校验或替换失败时，旧版本仍应能够启动，并给出手动发布页入口。

核心查价回归
------------
1. 依次切换 PvE、PvP 与赛季服；在 Tarkov 装备、背包或容器界面悬停物品，等待完整 Tooltip 后按 Q。
2. 检查最近低价、24h 均价、采样时间、建议挂价、预估净到手和推荐出售渠道。
3. 关闭智能挂价时建议价使用最近低价；开启后快速结果先出现，历史分析完成后原位更新。
4. 验证挂单少于 10、两项价格明显分歧和采样过旧时均有风险提示。
5. 当查价卡片遮住 Tooltip（包括只遮一部分）时，卡片应短暂避让后完成截图并恢复。
6. 装备页签被容器遮挡时，成就页签回退只能在 Tooltip 严格定位且本地唯一匹配时放行。
7. 弹药和弹药包应显示弹道数据卡，不显示普通物品出售卡。
8. 赛季服应显示独立的当前价、24h 均价、历史智能估价与采样时间；JSON 故障后选择 GraphQL 回退时，提示应说明赛季服沿用缓存。

配方与界面回归
--------------
1. 关注配方勾选后，当前产物和配方展开状态、选中项及滚动位置保持不动。
2. 查到关注材料时，浮窗在价格建议与 API 明细之间显示独立暖色配方区域；最多直显三项用途。
3. 切换浅色、深色、夜蓝、樱粉和高对比度主题；主界面换色，局内悬浮窗仍保持暗色。
4. 配方树列宽、展开状态、字体大小、主窗口与浮窗位置在重启后保持。
5. F9 局内控制窗和 F10 日志窗可拖动；关闭再打开后恢复位置且不主动抢游戏焦点。

反馈问题
--------
优先发送“文件 → 导出诊断包”生成的 ZIP，并说明 Windows 版本、显示器缩放、Tarkov 分辨率/窗口模式、PvE/PvP/赛季服、操作步骤与预期结果。

安全边界
--------
程序只做截图、OCR、本地缓存查询、浮窗与本地提醒；不会点击或移动鼠标、读取游戏内存、注入游戏进程或修改游戏文件。自动更新只替换本助手解压目录中的受管程序文件。
